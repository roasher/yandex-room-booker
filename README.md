# yandex-room-booker
Бот для сотрудников Яндекса, который умеет автоматически занимать переговорки под встречу. Актуально для переговорок, возможность забронировать которые открывается в определенное время. Бот забронирует их для вас.

В конфигурации `room-booker` дата, день недели и время задаются отдельными полями:

- `date` — конкретная дата в формате `YYYY-MM-DD`, например `"2026-10-05"`.
- `day-of-week` — целое число от `1` (понедельник) до `7` (воскресенье).
- `time` — обязательное время в формате `HH:mm` или `HH:mm:ss`.

Нужно указать хотя бы одно из полей `date` и `day-of-week`. Если указаны оба,
используется конкретная дата и проверяется её день недели. Несовпадение — ошибка конфигурации:
например, `"date": "2026-10-05", "day-of-week": 2` не пройдёт проверку, потому что это понедельник.

Например, следующий понедельник в 18:30:

```json
{
  "room-booker": {
    "enabled": true,
    "meeting-name": "Встреча",
    "room": "stroganov-yoga",
    "day-of-week": 1,
    "time": "18:30",
    "duration": "1h30m"
  }
}
```

Для конкретного числа замените `"day-of-week": 1` на `"date": "2026-10-05"`
или оставьте оба поля для дополнительной проверки дня недели.
Нумерация дней: `1` — понедельник, `2` — вторник, `3` — среда, `4` — четверг,
`5` — пятница, `6` — суббота, `7` — воскресенье.
Если `date` не задана, номер дня недели выбирает ближайший указанный день **после сегодня**:
в понедельник `"day-of-week": 1` выберет понедельник через неделю. Дата вычисляется один раз при запуске в
`room-booker.time-zone` (по умолчанию `Europe/Moscow`) и не меняется во время ожидания.
Это разовое бронирование, а не еженедельное повторение.

Прежнее поле `start` заменено на `date` и `time`: например,
`"start": "2026-10-05T18:30:00"` нужно заменить на `"date": "2026-10-05", "time": "18:30"`.

Когда начинать бронирование, бот определяет по `bookable-ahead` переговорки из
`src/main/resources/rooms.yml`: например, `2d` означает за 48 часов.
Пример запуска и настройки авторизации — в `run.sh.example`.

В блоке конфигурации `run.sh` можно отключать целые строки через `#`, например:

```text
#    "date": "2026-10-05",
    "day-of-week": 1,
    "time": "18:30",
```

Пробелы перед `#` допустимы. Скрипт удаляет такие строки перед передачей JSON приложению;
символ `#` внутри строковых значений сохраняется. Остальная конфигурация должна оставаться валидным JSON.
